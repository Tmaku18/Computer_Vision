Implementation

Blur is a convolution with a normalized kernel: box (equal weights), Gaussian, disk (defocus), or a rotated line (motion). The spatial implementation is the sum in equation (1), written as an explicit sum of shifted copies of the image. The frequency implementation zero-pads (linear mode) or wraps the kernel center to index 0 (circular mode), multiplies FFTs, and inverse-transforms. cv2.filter2D is used only as a cross-check, with the kernel flipped, because that function computes correlation.
