Module 2 · Calibration, measurement and two-camera geometry

Work through the steps in order. Step 1 calibrates the phone camera; Step 2 turns clicked pixels into real-world lengths with the perspective projection equations; Step 3 validates 20 measurements taken from more than 2 m and reports error statistics; the theory page derives how one point appears in two cameras.

Step 1

Camera calibration

Upload 20+ checkerboard photos from the phone. OpenCV estimates the focal lengths, principal point and lens distortion.

 Step 2

2D measurement

Undistort clicked pixels and map them to the object plane with a homography (or the pinhole equations at a known distance).

 Step 3

Validation (20 measurements)

Compare measured lengths with tape-measured ground truth at > 2 m and report MAE, RMSE, bias and confidence intervals.

 Theory

Point P seen by two cameras

Derivation of the image-to-image relationship for a static camera and an oblique second camera, with an interactive check.

 Report

Printable report

Calibration results, validation table and statistics, and the derivation, ready to save as PDF.

Source code

Command-line scripts (Python and MATLAB) live in HW1/; this site calls the same cv_core.py module. Each script starts with a README block explaining how to run it.
