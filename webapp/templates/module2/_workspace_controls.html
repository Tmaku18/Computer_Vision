1 · Photo

Use the same phone and orientation (landscape) as the calibration photos.

2 · Reference plane

The board must lie flat on the same plane as the object (e.g. taped to the same wall).

Order: top-left, top-right, bottom-right, bottom-left. Default is a US Letter sheet (11 × 8.5 in).

3 · Camera distance pinhole method

The pinhole method assumes the plane is perpendicular to the optical axis at this distance: \(X = Z\,(u - c_x)/f_x\). Leave empty to use only the homography.
